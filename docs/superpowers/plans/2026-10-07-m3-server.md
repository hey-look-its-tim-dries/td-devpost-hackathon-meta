# M3: The Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two browsers see each other's Hands and swarms: a Hand laid in one browser rises in every other, and players in the same region see each other as ink creatures.

**Architecture:** A Cloudflare Worker in `server/` with a `World` Durable Object (placements, D1 writes, the overlap check shared with the client) and `Room` Durable Objects (WebSocket presence, nothing stored). The game stays static; `src/net.js` talks to the Worker, `src/net/wire.js` is the binary protocol, and `main.js` gets Hands from `GET /world`, lays through `POST /hands`, and draws other players from room snapshots. The server imports the game's pure modules by relative path, so one overlap check and one validation serve both sides.

**Tech Stack:** Cloudflare Workers, Durable Objects (hibernatable WebSockets), D1, wrangler 4 (dev dependency in `server/` only), plain ES modules, `node:test`, puppeteer-core from the parent folder for the browser check.

**Spec:** `docs/superpowers/specs/2026-10-07-m3-server-design.md` (parent: `docs/superpowers/specs/2026-10-04-handbit-atlas-design.md`, sections 6.2, 6.3, 8.4, 10).

## Global Constraints

- The game keeps no build step and no dependencies; `wrangler` is the only dev dependency and lives in `server/package.json`.
- `src/world/*`, `src/hand/*`, `src/net/wire.js` and `src/world/mine.js` never import three.js or touch `window`/`document` (the server and workers import them).
- Only DNA (Palm DNA, 5 x Print DNA), pose, name and a random token leave the device. The server stores no IP, no region, no tracking data, no geometry.
- `localStorage` keys: `pwc.hand.v1` (your Hand, now also `id` and `pending`), `pwc.token.v1` (the device token).
- Validation on the server equals `checkHand` on the client: Palm DNA v1 of `28 + 13 * lines` bytes, five 44-byte Print DNA v1, known class and line-kind indices, name 1 to 40 characters after trimming, pose `x z rot` finite with `hypot(x, z) <= 100000`, `mirror` false.
- Overlap rule (spec 6.2 as M2 scaled it): 60 m cells, at most one sample of the new Hand within one cell of land, the Source (radius `SOURCE_RADIUS`) counts as land.
- Rooms: at most 200 sockets, region from `CF-IPCountry`, pose in every 200 ms, snapshot out at most every 250 ms, a player silent for 5 s leaves the snapshot, a socket over 20 messages per second is closed. Nothing stored.
- Wire format: pose = `float32 x, y, z, yaw, pitch` + `uint8 mode` (21 bytes, little-endian); snapshot = `uint16 count` + per player `uint16 id` + pose (21 bytes).
- Player-facing copy has no em dashes. Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- `PATH=/opt/homebrew/bin:$PATH node --test tests/*.test.mjs` stays green (112 + the tests below).
- `wrangler login` and `wrangler deploy` are Tim's. Every check in this plan runs against `wrangler dev` locally.

## Review Focus

1. **A `laid` event for your own Hand.** The World DO broadcasts every lay, including yours; the client must not bake it twice. Pinned in Task 6 (`applyLaid` ignores an id already in `hands`).
2. **Two players laying the same spot within a second.** The second gets `conflict` with fresh fits, never a 500 and never an overlapping Hand in D1. Pinned in Task 4 (the server test lays the same pose twice).
3. **The Worker is down or slow at start.** The game still opens with the founders and your Hand within 4 s. Pinned in Task 5 (`fetchWorld` times out at 4 s and the test asserts the fallback).
4. **A snapshot with a player id the client has never seen, or one that vanished.** No growth without bound: creatures are made for new ids and freed for ids missing from two snapshots. Pinned in Task 7.
5. **A room past 200.** The client follows the `full` redirect once and does not loop. Pinned in Task 4's room test (a Room started with `?cap=1` in dev sends `full`).

```js
// the world on a grid: land and the Source are 0, every cell up to NEAR away knows its distance and owner
export function buildGrid(world, cell = 60) {
  let minX = -SOURCE_RADIUS, maxX = SOURCE_RADIUS, minZ = -SOURCE_RADIUS, maxZ = SOURCE_RADIUS;
  for (const h of world) for (const [X, Y] of BOX) {
    const [x, z] = toWorld(h.pose, X, Y);
    minX = Math.min(minX, x); maxX = Math.max(maxX, x); minZ = Math.min(minZ, z); maxZ = Math.max(maxZ, z);
  }
  const pad = 1.3 * SPAN, x0 = minX - pad, z0 = minZ - pad;
  const W = Math.ceil((maxX - minX + 2 * pad) / cell), H = Math.ceil((maxZ - minZ + 2 * pad) / cell);
  const dist = new Uint8Array(W * H).fill(255), owner = new Int8Array(W * H), queue = [];
  const inBox = ([X, Y]) => X > -200 && X < 300 && Y > -20 && Y < 640;
  for (let r = 0; r < H; r++) for (let c = 0; c < W; c++) {
    const x = x0 + (c + 0.5) * cell, z = z0 + (r + 0.5) * cell, source = Math.hypot(x, z) < SOURCE_RADIUS;
    const who = source ? -1 : world.findIndex((h) => { const p = toHand(h.pose, x, z); return inBox(p) && insideHand(h.shape, p[0], p[1]); });
    if (!source && who < 0) continue;
    dist[r * W + c] = 0;
    owner[r * W + c] = who;
    queue.push(r * W + c);
  }
  for (let q = 0; q < queue.length; q++) {
    const i = queue[q], d = dist[i] + 1, c = i % W;
    if (d > NEAR) continue;
    for (const j of [c > 0 ? i - 1 : -1, c < W - 1 ? i + 1 : -1, i - W, i + W]) if (j >= 0 && j < W * H && dist[j] > d) { dist[j] = d; owner[j] = owner[i]; queue.push(j); }
  }
  return { dist, owner, x0, z0, W, H, cell };
}

// one pose of the new Hand on the grid: out when more than one sample lies on land (or off the grid);
// otherwise how snug its coast is and whose land it touches. `samples` are in world metres, coast first.
export function fitAt(g, samples, coastCount, { x: px, z: pz, rot }) {
  const c = Math.cos(rot), s = Math.sin(rot);
  let overlap = 0, snug = 0;
  const next = new Set();
  for (let n = 0; n < samples.length; n++) {
    const [X, Y] = samples[n], gc = Math.floor((px + c * X + s * Y - g.x0) / g.cell), gr = Math.floor((pz + s * X - c * Y - g.z0) / g.cell);
    if (gc < 0 || gr < 0 || gc >= g.W || gr >= g.H) continue; // off the grid is open sea
    const d = g.dist[gr * g.W + gc];
    if (d <= 1 && ++overlap > 1) return null;
    if (n < coastCount && d >= 2 && d <= NEAR) { snug++; next.add(g.owner[gr * g.W + gc]); }
  }
  return { snug, next: [...next] };
}

export function overlaps(world, shape, pose) {
  const { coast, inner } = handSamples(shape), samples = [...coast, ...inner].map(([X, Y]) => [X * WORLD, Y * WORLD]);
  return fitAt(buildGrid(world), samples, coast.length, pose) === null;
}
```

Then `findFits` becomes:

```js
export function findFits(world, shape, { cell = 60, rotations = 48, stride = 3, keep = 3, apart = 3000 } = {}) {
  const g = buildGrid(world, cell), { dist, x0, z0, W, H } = g;
  const { coast, inner } = handSamples(shape), samples = [...coast, ...inner].map(([X, Y]) => [X * WORLD, Y * WORLD]);
  const mouths = riverMouths(shape), open = world.flatMap((h) => riverMouths(h.shape).map((m) => worldMouth(h.pose, m)));
  const centres = world.map((h) => toWorld(h.pose, 0, 230));
  const found = [];
  // ponytail: every pose scored in one pass on the main thread (~0.25 s); a worker when the world grows past a few dozen Hands
  for (let i = 0, k = 0; i < W * H; i++) {
    if (dist[i] !== 2 || k++ % stride) continue; // the frontier: two cells off the coast (one cell is the overlap margin)
    const fx = x0 + ((i % W) + 0.5) * cell, fz = z0 + (Math.floor(i / W) + 0.5) * cell;
    for (let q = 0; q < rotations; q++) {
      const rot = (q / rotations) * Math.PI * 2, c = Math.cos(rot), s = Math.sin(rot);
      for (const [ax, ay] of ANCHORS) {
        const pose = { x: fx - (c * ax + s * ay) * WORLD, z: fz - (s * ax - c * ay) * WORLD, rot, mirror: false };
        const at = fitAt(g, samples, coast.length, pose);
        if (!at || !at.snug) continue;
        let rivers = 0;
        for (const m of mouths) {
          const w = worldMouth(pose, m);
          if (open.some((o) => Math.hypot(o.at[0] - w.at[0], o.at[1] - w.at[1]) < 400 && o.dir[0] * w.dir[0] + o.dir[1] * w.dir[1] < -0.82)) rivers++; // within 35 degrees of head-on
        }
        const centre = toWorld(pose, 0, 230);
        const crowd = centres.filter(([x, z]) => Math.hypot(x - centre[0], z - centre[1]) < 1.6 * SPAN).length;
        const fit = { pose, rivers, snug: at.snug / coast.length, centre, next: at.next };
        fit.score = scorePose({ rivers, snug: fit.snug, distance: Math.hypot(centre[0], centre[1]), crowd });
        found.push(fit);
      }
    }
  }
  found.sort((a, b) => b.score - a.score);
  const best = [];
  for (const f of found) {
    if (best.every((b) => Math.hypot(b.centre[0] - f.centre[0], b.centre[1] - f.centre[1]) >= apart)) best.push(f);
    if (best.length === keep) break;
  }
  return best;
}
```

Note the one behaviour change: a sample off the grid used to rule the pose out; now it counts as open sea (the server checks poses the client proposed against a possibly larger world, and the padding makes the two agree for every real fit). The BFS no longer wraps rows.

```js
// src/world/mine.js
// Your own Hand, kept on this device: its DNA, where it lies, and its name. Nothing else: no images,
// no tracking data. `storage` is localStorage in the page, a stand-in in tests. `checkHand` is the one
// gate for a Hand coming from storage or from the network, on the client and on the server. Pure.
import { unpackPalm, unpackPrint, toB64, fromB64, palmBytes } from '../hand/dna.js';

const KEY = 'pwc.hand.v1';
const REACH = 100000; // metres from the Source a Hand may lie

const bytes = (v) => (typeof v === 'string' ? fromB64(v) : v instanceof Uint8Array ? v : Array.isArray(v) ? Uint8Array.from(v) : null);

export function checkHand(v) {
  try {
    if (!v || !Array.isArray(v.prints) || v.prints.length !== 5 || ![v.pose?.x, v.pose?.z, v.pose?.rot].every(Number.isFinite)) return null;
    if (Math.hypot(v.pose.x, v.pose.z) > REACH || v.pose.mirror) return null;
    const name = String(v.name ?? '').trim().slice(0, 40);
    if (!name || String(v.name).trim().length > 40) return null;
    const palm = bytes(v.palm), prints = v.prints.map(bytes);
    if (!palm || prints.some((p) => !p)) return null;
    if (palm.length < 28 || palm.length !== palmBytes(unpackPalm(palm).lines.length) || prints.some((p) => p.length !== 44)) return null;
    if (prints.some((p) => !unpackPrint(p).cls) || unpackPalm(palm).lines.some((l) => !l.kind)) return null; // unpack throws on a version it does not know
    return { palm, prints, pose: { x: v.pose.x, z: v.pose.z, rot: v.pose.rot, mirror: false }, name };
  } catch {
    return null;
  }
}

export function saveHand(storage, { palm, prints, pose, name, id, pending }) {
  storage.setItem(KEY, JSON.stringify({ palm: toB64(palm), prints: prints.map(toB64), pose: { x: pose.x, z: pose.z, rot: pose.rot, mirror: !!pose.mirror }, name, ...(id ? { id } : {}), ...(pending ? { pending: true } : {}) }));
}

export function loadHand(storage) {
  try {
    const v = JSON.parse(storage.getItem(KEY)), h = checkHand(v);
    return h && { ...h, id: typeof v.id === 'string' ? v.id.slice(0, 64) : undefined, pending: !!v.pending };
  } catch {
    return null;
  }
}

export const forgetHand = (storage) => storage?.removeItem(KEY);
```

```js
// src/net/wire.js
// The room protocol, binary and little-endian. A pose is 21 bytes: float32 x, y, z, yaw, pitch and a
// uint8 mode (0 fly, 1 atelier, 2 merge, 3 rise). A snapshot is uint16 count, then uint16 id + pose
// per player. Pure: the page, the Room Durable Object and tests.
export const POSE_BYTES = 21;
const FIELDS = ['x', 'y', 'z', 'yaw', 'pitch'];

export function encodePose(p, out = new Uint8Array(POSE_BYTES), offset = 0) {
  const v = new DataView(out.buffer, out.byteOffset + offset, POSE_BYTES);
  FIELDS.forEach((k, i) => v.setFloat32(i * 4, +p[k] || 0, true));
  v.setUint8(20, p.mode & 255);
  return out;
}

export function decodePose(b, offset = 0) {
  const v = new DataView(b.buffer, b.byteOffset + offset, POSE_BYTES), p = { mode: v.getUint8(20) };
  FIELDS.forEach((k, i) => (p[k] = v.getFloat32(i * 4, true)));
  return p;
}

export function encodeSnapshot(list) {
  const out = new Uint8Array(2 + list.length * (2 + POSE_BYTES)), v = new DataView(out.buffer);
  v.setUint16(0, list.length, true);
  list.forEach(({ id, pose }, i) => { const o = 2 + i * (2 + POSE_BYTES); v.setUint16(o, id & 0xffff, true); encodePose(pose, out, o + 2); });
  return out;
}

export function decodeSnapshot(b) {
  if (b.length < 2) return [];
  const v = new DataView(b.buffer, b.byteOffset, b.byteLength), n = v.getUint16(0, true);
  if (b.length < 2 + n * (2 + POSE_BYTES)) return [];
  return Array.from({ length: n }, (_, i) => { const o = 2 + i * (2 + POSE_BYTES); return { id: v.getUint16(o, true), pose: decodePose(b, o + 2) }; });
}
```

```js
// server/src/worker.js
// Palm Whorl Cities' server: the world's Hands (D1, through the World Durable Object) and live rooms
// (Room Durable Objects). Nothing about a hand but its DNA, pose and name ever arrives here.
export { World } from './world.js';
export { Room } from './room.js';

const CONTINENT = { EU: 'eu', NA: 'na', SA: 'sa', AS: 'as', AF: 'af', OC: 'oc' };
const MAX_BODY = 8192;

const cors = (req, env, extra = {}) => {
  const origin = req.headers.get('Origin') ?? '', allowed = (env.ORIGINS ?? '').split(',').includes(origin);
  return { 'Access-Control-Allow-Origin': allowed ? origin : (env.ORIGINS ?? '').split(',')[0], 'Access-Control-Allow-Methods': 'GET, POST, DELETE, OPTIONS', 'Access-Control-Allow-Headers': 'Content-Type', 'Vary': 'Origin', ...extra };
};
const json = (req, env, body, status = 200, extra = {}) => new Response(JSON.stringify(body), { status, headers: cors(req, env, { 'Content-Type': 'application/json', ...extra }) });

export default {
  async fetch(req, env) {
    const url = new URL(req.url), path = url.pathname;
    if (req.method === 'OPTIONS') return new Response(null, { status: 204, headers: cors(req, env) });
    const world = env.WORLD.get(env.WORLD.idFromName('world'));
    if (path === '/world' && req.method === 'GET') {
      const r = await world.fetch(new Request('https://world/world', { headers: { 'If-None-Match': req.headers.get('If-None-Match') ?? '' } }));
      return new Response(r.body, { status: r.status, headers: cors(req, env, { 'Content-Type': 'application/json', 'ETag': r.headers.get('ETag') ?? '', 'Cache-Control': 'public, max-age=10' }) });
    }
    if (path === '/hands' && req.method === 'POST') {
      if (+(req.headers.get('Content-Length') ?? 0) > MAX_BODY) return json(req, env, { error: 'too big' }, 413);
      const text = await req.text();
      if (text.length > MAX_BODY) return json(req, env, { error: 'too big' }, 413);
      const r = await world.fetch(new Request('https://world/hands', { method: 'POST', body: text, headers: { 'CF-Connecting-IP': req.headers.get('CF-Connecting-IP') ?? 'local' } }));
      return json(req, env, await r.json(), r.status);
    }
    const del = path.match(/^\/hands\/([\w-]{1,64})$/);
    if (del && req.method === 'DELETE') {
      const r = await world.fetch(new Request(`https://world/hands/${del[1]}`, { method: 'DELETE', body: await req.text() }));
      return r.status === 204 ? new Response(null, { status: 204, headers: cors(req, env) }) : json(req, env, await r.json(), r.status);
    }
    if (path === '/room') {
      if (req.headers.get('Upgrade') !== 'websocket') return json(req, env, { error: 'websocket only' }, 426);
      const region = url.searchParams.get('region') ?? CONTINENT[req.headers.get('CF-IPCountry-Continent') ?? ''] ?? regionOf(req.headers.get('CF-IPCountry')) ?? 'eu';
      const shard = Math.max(0, +(url.searchParams.get('shard') ?? 0) | 0), name = `${region}-${shard}`;
      const room = env.ROOM.get(env.ROOM.idFromName(name));
      return room.fetch(new Request(`https://room/?name=${name}&cap=${url.searchParams.get('cap') ?? 200}`, { headers: req.headers }));
    }
    return json(req, env, { error: 'not found' }, 404);
  },
};

// a continent from a country code when the continent header is absent (dev, some proxies)
function regionOf(cc) {
  if (!cc) return null;
  if ('US CA MX GL'.includes(cc)) return 'na';
  if ('BR AR CL CO PE VE UY PY BO EC'.includes(cc)) return 'sa';
  if ('AU NZ'.includes(cc)) return 'oc';
  if ('CN JP KR IN ID TH VN PH MY SG TW HK PK BD'.includes(cc)) return 'as';
  if ('ZA NG EG KE MA GH ET'.includes(cc)) return 'af';
  return 'eu';
}
```

```js
// server/src/world.js
// The World: every laid Hand, in D1. One object, so two players laying Hands at the same moment are
// checked one after the other (spec 6.3). It also knows which Rooms are awake, to tell them of a lay.
import { DurableObject } from 'cloudflare:workers';
import { checkHand } from '../../src/world/mine.js';
import { overlaps, findFits } from '../../src/world/fit.js';
import { handShape } from '../../src/hand/shape.js';
import { unpackPalm, toB64, fromB64 } from '../../src/hand/dna.js';

const RATE_MS = 60000; // one lay per IP per minute
const BLOCK = ['hitler', 'nazi', 'nigger', 'faggot']; // ponytail: a short blocklist; a real filter if names ever go public beyond badges

const sha = async (s) => [...new Uint8Array(await crypto.subtle.digest('SHA-256', new TextEncoder().encode(s)))].map((b) => b.toString(16).padStart(2, '0')).join('');
const row = (r) => ({ id: r.id, name: r.name, palette: r.palette, side: r.side, palm: toB64(new Uint8Array(r.palm_dna)), prints: Array.from({ length: 5 }, (_, i) => toB64(new Uint8Array(r.prints).subarray(i * 44, i * 44 + 44))), pose: { x: r.x, z: r.z, rot: r.rot, mirror: false }, founder: !!r.founder, placed_at: r.placed_at });

export class World extends DurableObject {
  constructor(ctx, env) {
    super(ctx, env);
    this.lastByIp = new Map();
    this.rooms = new Set();
    this.cache = null; // { etag, body }
  }

  async hands() {
    const { results } = await this.env.DB.prepare('select h.*, p.name, p.palette from hand h join player p on p.id = h.player_id where h.placed_at is not null order by h.placed_at').all();
    return results.map(row);
  }

  async fetch(req) {
    const url = new URL(req.url);
    if (url.pathname === '/world') {
      if (!this.cache) { const hands = await this.hands(); this.cache = { etag: `"${hands.at(-1)?.placed_at ?? 0}-${hands.length}"`, body: JSON.stringify({ gen: 1, hands }) }; }
      if (req.headers.get('If-None-Match') === this.cache.etag) return new Response(null, { status: 304, headers: { ETag: this.cache.etag } });
      return new Response(this.cache.body, { headers: { ETag: this.cache.etag, 'Content-Type': 'application/json' } });
    }
    if (url.pathname === '/hands' && req.method === 'POST') return this.lay(req);
    const del = url.pathname.match(/^\/hands\/([\w-]+)$/);
    if (del && req.method === 'DELETE') return this.wash(del[1], req);
    if (url.pathname === '/rooms' && req.method === 'POST') { this.rooms.add(await req.text()); return new Response(null, { status: 204 }); }
    return Response.json({ error: 'not found' }, { status: 404 });
  }

  async lay(req) {
    let body;
    try { body = await req.json(); } catch { return Response.json({ error: 'bad json' }, { status: 400 }); }
    const token = typeof body?.token === 'string' && /^[A-Za-z0-9_-]{32,64}$/.test(body.token) ? body.token : null;
    const hand = checkHand(body);
    if (!token || !hand) return Response.json({ error: 'not a Hand' }, { status: 400 });
    if (BLOCK.some((w) => hand.name.toLowerCase().includes(w))) return Response.json({ error: 'that name is not available' }, { status: 400 });
    const ip = req.headers.get('CF-Connecting-IP') ?? 'local', now = Date.now();
    if (now - (this.lastByIp.get(ip) ?? -Infinity) < RATE_MS) return Response.json({ error: 'one Hand a minute' }, { status: 429 });
    const tokenHash = await sha(token);
    const mine = await this.env.DB.prepare('select h.*, p.name, p.palette from hand h join player p on p.id = h.player_id where p.token_hash = ?').bind(tokenHash).first();
    if (mine) return Response.json({ id: mine.id, pose: row(mine).pose }, { status: 409 });
    const world = (await this.hands()).map((h) => ({ pose: h.pose, shape: handShape(unpackPalm(fromB64(h.palm))), name: h.name }));
    const shape = handShape(unpackPalm(hand.palm));
    if (overlaps(world, shape, hand.pose)) {
      const fits = findFits(world, shape).map((f) => ({ ...f, names: f.next.map((i) => (i < 0 ? 'the Source' : world[i].name)) }));
      return Response.json({ conflict: true, fits });
    }
    this.lastByIp.set(ip, now);
    const pid = crypto.randomUUID(), hid = crypto.randomUUID(), palm = unpackPalm(hand.palm);
    await this.env.DB.batch([
      this.env.DB.prepare('insert into player (id, token_hash, created_at, name, palette) values (?, ?, ?, ?, ?)').bind(pid, tokenHash, now, hand.name, palm.palette),
      this.env.DB.prepare('insert into hand (id, player_id, side, palm_dna, prints, route, gen, x, z, rot, placed_at, founder) values (?, ?, ?, ?, ?, ?, 1, ?, ?, ?, ?, 0)').bind(hid, pid, palm.side, hand.palm, Uint8Array.from(hand.prints.flatMap((p) => [...p])), 'eye', hand.pose.x, hand.pose.z, hand.pose.rot, now),
    ]);
    this.cache = null;
    const laid = { id: hid, name: hand.name, palette: palm.palette, side: palm.side, palm: toB64(hand.palm), prints: hand.prints.map(toB64), pose: hand.pose, founder: false, placed_at: now };
    this.ctx.waitUntil(this.tell({ laid }));
    return Response.json({ id: hid, pose: hand.pose });
  }

  async wash(id, req) {
    let body;
    try { body = await req.json(); } catch { return Response.json({ error: 'bad json' }, { status: 400 }); }
    if (typeof body?.token !== 'string') return Response.json({ error: 'no token' }, { status: 400 });
    const r = await this.env.DB.prepare('delete from player where token_hash = ? and id = (select player_id from hand where id = ? and founder = 0)').bind(await sha(body.token), id).run();
    if (!r.meta.changes) return Response.json({ error: 'not yours' }, { status: 404 });
    await this.env.DB.prepare('delete from hand where id = ?').bind(id).run(); // cascade is off in D1 unless pragma'd per connection
    this.cache = null;
    this.ctx.waitUntil(this.tell({ left: id }));
    return new Response(null, { status: 204 });
  }

  // every awake Room hears of a lay or a wash; a Room that fails twice is forgotten
  async tell(event) {
    const text = JSON.stringify(event);
    await Promise.all([...this.rooms].map(async (name) => {
      const stub = this.env.ROOM.get(this.env.ROOM.idFromName(name));
      for (let i = 0; i < 2; i++) { try { const r = await stub.fetch(new Request('https://room/event', { method: 'POST', body: text })); if (r.ok) return; } catch {} }
      this.rooms.delete(name);
    }));
  }
}
```

```js
// server/src/room.js
// A live room: up to 200 players' poses, 5 Hz in, one snapshot out at most every 250 ms, and the
// World's lay events relayed as text. Hibernatable sockets, so an empty room costs nothing. Nothing
// here is stored; ids are per-room session numbers.
import { DurableObject } from 'cloudflare:workers';
import { encodeSnapshot, decodePose, POSE_BYTES } from '../../src/net/wire.js';

const TICK = 250, STALE = 5000, FLOOD = 20; // ms, ms, messages per second

export class Room extends DurableObject {
  constructor(ctx, env) {
    super(ctx, env);
    this.live = new Map(); // id -> { pose, at, count, second }
    this.timer = null;
    this.next = 1;
    this.name = null;
    for (const ws of ctx.getWebSockets()) { const a = ws.deserializeAttachment(); if (a) { this.next = Math.max(this.next, a.id + 1); this.name = a.name; } }
  }

  async fetch(req) {
    const url = new URL(req.url);
    if (url.pathname === '/event') { this.broadcast(await req.text()); return new Response(null, { status: 204 }); }
    const name = url.searchParams.get('name'), cap = +(url.searchParams.get('cap') ?? 200);
    const pair = new WebSocketPair(), [client, server] = Object.values(pair);
    const sockets = this.ctx.getWebSockets();
    if (sockets.length >= cap) {
      server.accept();
      server.send(JSON.stringify({ full: name.replace(/-(\d+)$/, (_, n) => `-${+n + 1}`) }));
      server.close(1000, 'full');
      return new Response(null, { status: 101, webSocket: client });
    }
    const id = this.next++ & 0xffff;
    if (!this.name) { this.name = name; this.ctx.waitUntil(this.env.WORLD.get(this.env.WORLD.idFromName('world')).fetch(new Request('https://world/rooms', { method: 'POST', body: name }))); }
    this.ctx.acceptWebSocket(server);
    server.serializeAttachment({ id, name });
    server.send(JSON.stringify({ hello: id }));
    return new Response(null, { status: 101, webSocket: client });
  }

  webSocketMessage(ws, msg) {
    const a = ws.deserializeAttachment();
    if (!a || typeof msg === 'string' || msg.byteLength !== POSE_BYTES) return;
    const now = Date.now(), e = this.live.get(a.id) ?? { count: 0, second: 0 };
    const second = Math.floor(now / 1000);
    if (second !== e.second) { e.second = second; e.count = 0; }
    if (++e.count > FLOOD) return ws.close(1008, 'too fast');
    e.pose = decodePose(new Uint8Array(msg));
    e.at = now;
    this.live.set(a.id, e);
    if (!this.timer) this.timer = setTimeout(() => this.tick(), TICK); // the first pose after a tick schedules the next
  }

  webSocketClose(ws) { const a = ws.deserializeAttachment(); if (a) this.live.delete(a.id); }
  webSocketError(ws) { this.webSocketClose(ws); }

  tick() {
    this.timer = null;
    const now = Date.now();
    for (const [id, e] of this.live) if (now - e.at > STALE) this.live.delete(id);
    const snap = encodeSnapshot([...this.live].filter(([, e]) => e.pose).map(([id, e]) => ({ id, pose: e.pose })));
    this.broadcast(snap);
  }

  broadcast(data) { for (const ws of this.ctx.getWebSockets()) { try { ws.send(data); } catch {} } }
}
```

```js
// src/others.js
// Other players in your room, each an ink creature like yours but lighter (5 strands), moved by the
// room's snapshots through a One Euro filter so 4 Hz looks like flight. Nearest `max` only. Pure.
import { createCreature } from './creature.js';
import { OneEuro } from './gesture.js';

export function createOthers({ max = 60 } = {}) {
  const live = new Map(); // id -> { creature, filter, target: [x, y, z], yaw, pitch, speed, missed }
  return {
    get count() { return live.size; },
    apply(snapshot, me, from = [0, 0, 0]) {
      const seen = new Set();
      const near = snapshot.filter((p) => p.id !== me).sort((a, b) => Math.hypot(a.pose.x - from[0], a.pose.z - from[2]) - Math.hypot(b.pose.x - from[0], b.pose.z - from[2])).slice(0, max);
      for (const { id, pose } of near) {
        seen.add(id);
        let e = live.get(id);
        if (!e) { e = { creature: createCreature({ strands: 5, points: 40, spacing: 2, radius: 13 }), filter: new OneEuro({ minCutoff: 1.0, beta: 0.3 }), pos: [pose.x, pose.y, pose.z], speed: 70, missed: 0 }; live.set(id, e); }
        e.target = [pose.x, pose.y, pose.z];
        e.yaw = pose.yaw; e.pitch = pose.pitch; e.missed = 0;
      }
      for (const [id, e] of live) if (!seen.has(id) && ++e.missed >= 2) live.delete(id);
    },
    update(dt, from) {
      for (const e of live.values()) {
        if (!e.target) continue;
        const p = e.filter.filter(e.target, dt), moved = Math.hypot(p[0] - e.pos[0], p[1] - e.pos[1], p[2] - e.pos[2]);
        e.speed += ((dt > 0 ? moved / dt : e.speed) - e.speed) * 0.2;
        e.pos = p;
        e.creature.update(dt, e.pos, { speed: e.speed, pitch: e.pitch ?? 0, turn: 0 });
      }
    },
    each(fn) { for (const [id, e] of live) fn(e.creature, id); },
  };
}
```
